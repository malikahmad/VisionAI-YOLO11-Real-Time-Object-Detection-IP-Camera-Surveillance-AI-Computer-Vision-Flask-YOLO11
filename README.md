# VisionAI-YOLO11-Real-Time-Object-Detection-IP-Camera-Surveillance-AI-Computer-Vision-Flask-YOLO11
An AI-powered real-time object detection and video surveillance platform built with Flask, YOLO11, OpenCV, and ByteTrack. Supports image and video detection, object tracking, live IP camera (RTSP) streaming, annotated video exports, and detection analytics.
